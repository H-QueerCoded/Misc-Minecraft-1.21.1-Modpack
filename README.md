This is a Minecraft 1.21.1 modpack made with [packwiz](https://packwiz.infra.link/).

To use this, create an instance in Prism Launcher (or similar), add the [packwiz installer bootstrap](https://packwiz.infra.link/tutorials/installing/packwiz-installer/), and set the instance pre-launch commands to `"$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://h-queercoded.github.io/Misc-Minecraft-1.21.1-Modpack/pack.toml`.

A few files will need to be manually downloaded on initial launch but then updates should be automatic.
